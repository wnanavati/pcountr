## What this project is
An R package, `pcountr`, that modernises the MS-DOS pollen-counting program
PCount. Full rationale and all design decisions are in `DESIGN.md`. The verified
spine (v0.1.0) is complete and tested.

## How to build & test (in a normal R environment with internet)
```r
# from the package root:
install.packages(c("yaml", "testthat", "devtools", "roxygen2"))  # first time
devtools::document()   # regenerate man/ and NAMESPACE from roxygen comments
devtools::install()    # install pcountr
devtools::test()       # run the testthat suite
devtools::check()      # full R CMD check (aim for 0 errors/warnings)
```

If `devtools` is unavailable, the lower-level equivalents work too:
```sh
R CMD INSTALL .
Rscript -e 'library(pcountr); ...'
```

## Quick smoke test
```r
library(pcountr)
dic  <- read_dic(system.file("extdata", "ECG.DIC",     package = "pcountr"))
site <- pollen_site("Little Mosquito Lake", dic)
cnt  <- read_cnt(system.file("extdata", "LMSH001.CNT", package = "pcountr"),
                 site = site, quiet = TRUE)
count_metrics(cnt)     # should reproduce LM23SH00.RPT numbers
```

## What lives where
- `R/` — package source (dictionary.R, read_cnt.R, pollen_count.R, metrics.R, yaml_io.R)
- `tests/testthat/` — golden + site regression tests
- `inst/extdata/` — the example data (ECG.DIC, 20 LMSH*.CNT files, LM23SH00.RPT)
- `DESIGN.md` / `ROADMAP.md` / `NEWS.md` — decisions, plan, changelog
- `man/` — currently empty; will be generated by `devtools::document()`

## Important notes
- **NAMESPACE is currently hand-written.** Once you run `devtools::document()`
  with roxygen, it will be generated from the `@export` tags in the R files. The
  roxygen comments are already in place, so documenting is safe.
- **The `yaml` fallback:** `R/yaml_io.R` contains a minimal built-in YAML emitter
  used when the `yaml` package isn't installed. With `yaml` installed it uses the
  real one. Don't delete the fallback without reason; it keeps the package usable
  in restricted environments.
- **Keep the DOS originals safe.** `PCOUNT.EXE` and the original `.CNT`/`.RPT`/
  `.DIC` files are irreplaceable ground truth. Keep a backup copy *outside* the
  working folder before letting any agent operate here.
